# 美术方向：命名系统、构图原型与实现配方

本文件是 science-video-factory 的视觉规范。目标不是"好看一点"，而是让每一镜都能被**执行**：色值精确到 hex、字号精确到 px、动效精确到帧与缓动曲线、图层精确到 z-index。

使用顺序：

1. 在「四套命名美术系统」里选一套（A/B/C/D），把色板与字号阶写进 `visual-style.md`。
2. 在「十二种构图原型」里选一个作为该镜的骨架，不要自创"标题 + 图表"版式。
3. 从「参考图拆解」把参考片拆成 layers / 光 / 字 / 动效，落到具体令牌。
4. 用 `templates/shot-starter`（A）或 `templates/shot-starter-noir`（B）起步，按模板 `DESIGN.md` 改造。
5. 交片前过 `docs/QUALITY.md` 的三点截图与校验清单。

## 0. 画布、网格与安全区

| 项目 | 横屏 1920×1080 | 竖屏 1080×1920 |
| --- | --- | --- |
| 外安全边距 | 156px（8.1%） | 88px（8.1%） |
| 顶部安全 | 96px | 120px |
| 字幕带（Remotion 渲染） | y ≥ 886px（82%） | y ≥ 1500px（78%） |
| 内容最大宽度 | 1608px | 904px |
| 推荐模块网格 | 96px | 72px |

硬规则：

- **y > 886px 只放装饰层**（暗角、颗粒、扫描线、雨、光带），不放可读文字。字幕由 Remotion 统一渲染，镜头画进去就是重复信息，且 `validate-episode` 会拒绝。
- 主要信息落在中央 1608×694 的"金框"内；贴边只允许结构线、刻度、出血图形。
- 三层景深是底线：**背景/氛围层 + 主体层 + 前景细节层**。任何一层缺失都会得到"灰底 + 一个图形"的 PPT 感。
- 画面必须有明确的明度分层：至少 3 档，推荐 0.04 / 0.10 / 0.22 / 0.55 / 0.92 五个明度台阶（0=黑，1=白）。主体与背景的明度差 ≥ 0.25。

z-index 约定（四套系统通用，模板已实现）：

```text
0  sky        底色与大气渐变
1  field      星场 / 网格 / 纹理
2  subject    主体几何（轨道、剖面、主体图形）
3  fore       前景细节（浮尘、雨、边缘刻度）
4  sweep      过程光效（扫描、光带、高光）
5  vignette   暗角（压在场景上、物体下）
6-8 type      文字层级（hero → 标签 → 注释）
9  bars       遮幅 / 画框 / 定位角
10 grain      颗粒（mix-blend-mode: overlay）
11 texture    扫描线 / 划痕 / 色差（最后叠加）
```

## 1. 四套命名美术系统

每套系统固定：色板（含使用比例）、字号阶、网格、材质配方、光影、镜头语言、适配题材。**同一 episode 只能选一套**；跨 episode 可以换，但要在 `visual-style.md` 写明系统代号。

| line 结构线 | `#1B3247` | 网格、分隔、刻度 | 20% |
| line-hi 高亮线 | `#2A4A63` | 主轴线、边框 | — |
| paper 主文字 | `#EAF2FA` | hero、标题 | 8% |

| --- | --- | --- | --- | --- | --- |
| hero 数字 | Cormorant Garamond 500 | 200–260px | 0.78 | −0.012em | `--paper` |

| 数据标签 | JetBrains Mono 400 | 16–18px | 1.3 | 0.06–0.18em | `--mist` |
| 轴/注释 | JetBrains Mono 400 | 14–16px | 1.2 | 0.08em | `--dim` |

网格：156px 外边距；96px 模块线（不画出来，只用于对位）；顶部 118px 处放水平标尺（每 36px 一刻度，每 4 格一主刻度）；主体圆心建议 (1252, 452)，外环半径 336；左侧文字栏 x=156，宽 ≤620。

材质与光：

```css
/* 冷辉光：大范围、低透明度、带模糊 */
background: radial-gradient(closest-side, rgba(95,227,208,.20) 0%, rgba(47,163,150,.07) 46%, rgba(4,7,14,0) 78%);
filter: blur(6px);

/* 暗角：径向 + 上下压暗，压四角不压主体 */
background:
  radial-gradient(74% 66% at 62% 44%, rgba(2,4,8,0) 42%, rgba(2,4,8,.44) 72%, rgba(2,4,8,.84) 100%),
  linear-gradient(180deg, rgba(2,4,8,.38) 0%, rgba(2,4,8,0) 24%, rgba(2,4,8,0) 72%, rgba(2,4,8,.5) 100%);
```

颗粒（确定性静帧，seed 固定）：

```html
<filter id="grain"><feTurbulence type="fractalNoise" baseFrequency=".86"
  numOctaves="4" stitchTiles="stitch" seed="7"/><feColorMatrix type="saturate" values="0"/></filter>
<rect width="100%" height="100%" filter="url(#grain)" opacity=".075" style="mix-blend-mode:overlay"/>
```

镜头语言：慢推（8s 内 scale 1→1.025）、环形进动（≤4°/8s）、卫星/数据点匀速绕行、扫描光带横穿（1.3s）、弧线绘制（stroke-dashoffset 1.1s）。转场优先"光带擦过 + 硬切"，不用缩放弹跳。

适配：天文、物理量级、工程原理、测量与误差、数据对比。反例：情感类叙事、儿童内容。

材质与光：

```css
/* 硬边斜切光柱：用 SVG polygon，不用模糊渐变，才有黑色电影的硬光 */
<linearGradient id="shaft-fill" x1="0" y1="0" x2="1" y2="1">
  <stop offset="0%"  stop-color="#DCE9F5" stop-opacity=".18"/>
  <stop offset="52%" stop-color="#C3CDDA" stop-opacity=".07"/>
  <stop offset="100%" stop-color="#DCE9F5" stop-opacity="0"/>
</linearGradient>
/* 边缘 2px 高光，才读得出"光的方向" */
<stroke> url(#shaft-edge) stroke-width="2"
```

颗粒更重：`opacity: .12`；暗角更深：边缘 `rgba(3,4,7,.92)`；叠一层 1px 竖向胶片划痕（opacity .5，`repeating-linear-gradient`），**不做**扫描线（那是系统 D 的语言）。

镜头语言：雨持续下落（400px 周期无缝循环）、物件从画外下坠（power3.out，不用 bounce）、白线硬切（0.35s 画出）、光柱扫入。禁止梦幻柔焦、禁止彩色辉光。

适配：开场、转折、悬念、结论宣言、人物/历史故事。反例：需要精确数据的机制解释。

## 2. 十二种构图原型

每个原型给：焦点、层次、动效职责、适配系统。**选原型而不是自由排版**，是避免 PPT 感最有效的一步。

| # | 原型 | 焦点 | 三层职责 | 动效职责 | 常配系统 |
| --- | --- | --- | --- | --- | --- |
| 1 | 中心对撞 | 画面中心的碰撞点/爆炸点 | 背景辐射场 / 两股对向力 / 前景飞屑 | 两股力对向加速 → 碰撞帧（1–2 帧停顿）→ 冲击波扩散 | A/D |
| 2 | 非对称三分 | 1/3 处的 hero 数字或主体 | 左侧留白与文字 / 右侧主体 / 前景前景刻度或尘埃 | hero 上浮 + 主体缓慢推近 + 刻度逐格点亮 | A/C |
| 3 | 环形轨道 | 轨道上的动点 | 星场网格 / 同心环 + 行星 / 准星与弧段 | 环绘制 → 动点匀速绕行 → 尾帧锁定 | A |
| 4 | 矩阵热区 | 最热的一格 | 暗网格 / 热力色块 / 扫描线 | 按数据顺序点亮格子（stagger 2–3 帧）→ 扫描线扫过 → 峰值格脉冲一次 | D/A |
| 5 | 剖面层叠 | 爆炸图的中轴 | 底色 / 分层结构（6–10 层）/ 连接线与标注 | 层逐层炸开（y 偏移 40–90px，错峰 4–6 帧）→ 标注跟随 | C/A |
| 6 | 巨型字压图 | 字形与图像的叠压区 | 图像/纹理 / 巨型字 / 前景颗粒与划线 | 字形从 1.08 收到 1.00，图像反向微推（视差 12px） | B/C/D |
| 7 | 卡片阵列 | 被翻开的卡 | 背景光 / 卡片网格（6–9 张）/ 卡片投影 | 卡片 stagger 入场 → 目标卡浮起、其余压暗 → 卡片翻转 90° | C/B |
| 8 | 留白宣言 | 一行字或一个符号 | 极简渐变 / 单一元素 / 颗粒 | 元素在 0.6s 内从 0→1 显影，随后 6s 几乎不动（留白是内容） | B/C |
| 9 | 双窗对照 | 两个窗口的差异点 | 背景 / 左右两个等大窗口 / 中间分隔与差异标注 | 左先入 → 右后入（滞后 6–8 帧）→ 差异处描红 | A/C/D |
| 10 | 时间轴切片 | 当前时刻的切片 | 长轴与刻度 / 切片面板 / 流光 | 轴从一端绘制 → 切片滑到目标帧 → 面板内容切换 | C/D |
| 11 | 透视网格走廊 | 走廊尽头的目标 | 透视网格 / 走廊侧壁与目标 / 前景速度线 | 网格向观众推进（scale 1→1.3，6–8s）、目标逐渐变大 | D/A |
| 12 | 书页跨版 | 跨页的图文关系 | 纸底与纸纹 / 左文右图 / 纸片投影与折角 | 翻页式平移（x −40→0，power2.out）+ 图版缓推 1.02 | C |

### 使用规则

- 一镜一个原型。切换原型 = 切换镜头，用硬切或光擦转场，不要在同一镜里混排两种骨架。
- 每个原型至少要有 **两个有意义的状态变化**（4 秒以上镜头）：例如"绘制 → 锁定"、"展开 → 标注"、"对比 → 结论"。
- 原型的焦点必须在 0.5s 内可辨识；观众不需要读文字就知道该看哪里。
- 12 个原型的默认重心都不在画面正中央：正中央只留给"对撞"和"留白宣言"。

## 3. 反 PPT 清单

出现任意 2 条即视为不合格镜头，必须重做构图。

1. 居中标题 + 副标题 + 图表 + 统一淡入。
2. 每镜使用同一种入场动画（全部 fade / 全部从左滑入）。
3. 纯色或灰色背景，没有明度渐变与景深。
4. 默认字体：Arial、系统黑体、Roboto；没有字体搭配。
5. 三行以上的要点列表（bullet list）。
6. 与内容无关的 icon 装饰、圆角卡片堆叠、阴影全一致。
7. 图形全部居中、等距、等大，没有主次。
8. 画面亮度均匀：没有暗角、没有颗粒、没有一处高光。
9. 图表没有直接标注、没有高亮、没有"当前值"。
10. 字号层级只有两档（标题 + 正文）。
11. 元素贴边或压进字幕带（y > 886px）。
12. 动画只有 fade，没有位移/绘制/形变/节奏变化。
13. 高饱和色占满整屏（正确做法：高饱和 ≤10% 面积）。
14. 用 emoji 当图示。
15. 把 ShotBrief 标题、镜头序号（`SHOT 001`）或整句 caption 画进镜头。

自查一句话：**把这一帧截图发给没看过分镜的人，他能否在 1 秒内指出焦点，并说出"这里在发生什么变化"？**

## 4. 从参考图拆解到实现

参考来源优先级：电影剧照 / 摄影集 / 唱片封面 / 博物馆图录 / 科学可视化海报。避免直接照搬 UI 截图。

### 4.1 五步拆解

1. **明度分层**：把参考图转黑白并降采样，数出 3–5 个明度台阶，记录各台阶面积比。目标：主体与背景差 ≥0.25，画面有明确的暗部与高光。把台阶写成 5 个 hex（例如 `#04070E / #0A0D14 / #141924 / #C3CDDA / #F4F0E6`）。
2. **区域划分**：在参考图上画 3×3 网格与黄金分割线，标出焦点、视觉动线（通常 2 条：一条主、一条回）、留白区。输出一句话："焦点在 (x%, y%)，主轴从左上到右下"。
3. **材质识别**：逐项确认存在与否——颗粒、纸张、扫描线、辉光、暗角、色差、划痕、景深模糊。每项写配方参数（频率、透明度、模糊半径、混合模式）。
4. **字体测量**：量 hero 字高占画面高度的比例（常见 12%–22%），记录字重、字距、行数、对齐方式。换算成 1080p 的 px。
5. **动效节拍**：如果是视频参考，记录镜头运动、转场点、节奏（每秒几个视觉事件）。落到 8 秒 × 24fps = 192 帧的网格上，写进 `beats`。

### 4.2 反例拆解：旧样片 `friendly-robot-showcase/shot-002`

参考帧：`renders/friendly-robot-showcase/preview/shot-002/frame-01-at-2.5s.png`。

诊断（为什么"扁平、灰、小字幕"）：

| 问题 | 具体表现 | 处方 |
| --- | --- | --- |
| 无明度分层 | 全图集中在 0.70–0.85 明度，只有机器人本体一处亮块 | 底压到 0.03–0.08，主体提到 0.85+，加一处 0.95 高光 |
| 无光源方向 | 机器人受光均匀，没有投影、没有轮廓光 | 定一个主光方向（如右上 35°），加 2px 冷色轮廓光 + 长投影 |
| 无景深三层 | 背景就是一块灰色渐变，没有前景 | 加背景层（星场/网格/辉光）、前景层（浮尘/刻度/暗角） |
| 填充率失衡 | 主体占画面 60% 且居中，留白无意义 | 主体移到三分线，左侧 1/3 留给排版，右侧留给数据 |
| 字体缺位 | 无文字层级，字幕 30px 偏小 | 用 A 系统字号阶：hero 200px+ / 标签 16–20px / 字幕升级到 42px |
| 无材质 | 纯数字渲染，无颗粒、无暗角 | 加 feTurbulence 颗粒 opacity .075 + 径向暗角 |
| 动效无职责 | 只有整体旋转 | 改为"引入（轮廓光扫过）→ 过程（部件组装/扫描）→ 解决（锁定 + 数据浮现）" |

修法：直接把该镜迁到系统 A 或 D，用原型 2（非对称三分）重排；hero 区给结论数字，机器人缩到右侧三分线内做主体，背景补网格 + 星场，前景补刻度与浮尘。

### 4.3 从拆解到代码

拆解结果 → 代码的顺序固定为：**色板令牌 → 网格坐标 → 图层清单 → 字号阶 → 时间轴 beats**。

```text
明度台阶  → CSS :root 变量（--ink-0 … --paper）
区域划分  → 绝对定位坐标（left/top 写 px，不写百分比）
图层清单  → 顶层 .clip 元素 + z-index（见 §0）
字体测量  → font-size / letter-spacing / line-height
动效节拍  → GSAP 位置参数（秒）+ 缓动曲线
```

每个坐标都写死 px 是刻意的：1080p 画布固定，百分比会让不同字号下的对位漂移。

## 5. 动效规范

| 用途 | 时长（24fps） | 缓动 | 位移/变化量 |
| --- | --- | --- | --- |
| 文字入场 | 12–20 帧 | `power3.out` / `power4.out` | y 14–34px + 0→1 |
| 大字/主体入场 | 18–30 帧 | `power4.out` | scale 0.94→1.00 |
| 线条/弧线绘制 | 18–28 帧 | `power2.inOut` | dashoffset 1→0 |
| 物件下坠/落定 | 22–30 帧 | `power3.out`（不用 bounce） | y −300→0 + rotation |
| 环境漂移 | 全程 | `sine.inOut` / `none` | scale ≤1.03、位移 ≤20px |
| 扫描/擦拭 | 24–40 帧 | `power2.inOut` | 横穿 900–1500px |
| 转场 | 8–14 帧 | 硬切优先 | 亮度闪 ≤1 帧 |

节奏规则：

- 8 秒镜头：建立 0–1.5s、过程 1.5–5.5s、解决 5.5–7.5s、尾帧留 0.5s。
- 4 秒以上镜头至少两个有意义的状态变化。
- 同一 episode 内不重复使用同一种入场方式；至少混用"绘制、位移、缩放、遮罩、逐格点亮"中的三种。
- 循环动画必须有限：`repeat: -1` 只在根节点声明了有限 `data-duration` 时允许，且优先用有限循环次数（`repeat: 3`）精确铺满时长。

## 7. 电影感叠加层（Remotion）

`src/components/CinematicOverlay.tsx`，挂载在镜头资产之上、字幕之下，纯视觉、不改变时间轴：

- 暗角：`radial-gradient(74% 68% at 50% 46%, transparent 44%, rgba(2,4,8,.34) 74%, rgba(2,4,8,.72) 100%)`
- 上下压暗：顶部 16% 到 0、底部 24% 到 50%
- 颗粒：SVG `feTurbulence`（seed 17）平铺 512px，opacity .05，`mix-blend-mode: overlay`，每 3 帧位移 1px（由帧号派生，确定性）
- 扫描线：4px 周期，opacity .07
- 可调 props：`grainOpacity` / `scanlineOpacity` / `vignetteOpacity`

## 8. 字体与对比度

字体获取：HyperFrames 编译期自动从 Google Fonts 拉取并缓存，`font-family` 里出现的每个非通用族都必须能被 `<link href="https://fonts.googleapis.com/css2?...">` 解析，否则 `check --strict` 报 `font_family_without_font_face`。

| 用途 | 推荐 | 备注 |
| --- | --- | --- |
| 中文无衬线 | Noto Sans SC 400/500/700 | 标签、正文、标题 |
| 中文衬线 | Noto Serif SC 600 | 巨型字、纸本、竖排 |
| 拉丁展示 | Cormorant Garamond 500/600 italic | 数字、引文 |
| 等宽/数据 | JetBrains Mono 400/500 | 遥测、刻度、编号 |

对比度：正文/标签 ≥ 4.5:1，大字号（≥36px 粗体）≥ 3:1。小字不要压在渐变边缘、光带或月亮亮面上；拿不准就加一层局部压暗 scrim（`rgba(4,7,14,.55)`）。

# kid-phantom-pv 视觉风格

## 美术系统

月夜黑色电影 + 漫画网点印刷。参考气质：《The Third Man》的斜投影与硬光、Saul Bass 的极简剪影海报、日本漫画的网点与套色错位。全部元素为原创几何绘制，不使用任何官方角色、Logo 或原画。

## 色板（角色化）

| Hex | 角色 |
|---|---|
| `#07070A` | 底色 / 剪影 / 遮幅 |
| `#EDE7DA` | 骨白：月亮、主体字、高光 |
| `#C81E3A` | 绯红：预告函细线、虹膜、end card、印章 |
| `#D4AF6A` | 暗金：单片眼镜、帽带、细框、小标签 |
| `#101426` | 夜蓝：夜空与烟雾的中间调 |

## 字体与字号阶（1920x1080）

- 展示字：Cinzel 700–900（罗马大写标签、KID、PHANTOM THIEF），巨型 260–380 px。
- 衬线展示：Cormorant Garamond 400/600（英文副行、斜体点缀），48–120 px。
- 中文：Noto Serif SC 400/900（预告函、怪盗），26–300 px；回退 Microsoft YaHei / SimSun。
- 标签：16–22 px，字距 0.34–0.56 em，暗金或 62–68% 骨白。
- 层级：每镜最多三层字（巨型字 / 标签 / 微注），字号比不小于 1:4。

## 材质配方

- 颗粒：Canvas 生成 256×256 种子噪声，叠加 `overlay`，透明度 0.20–0.24，每 2–3 帧换一次偏移（种子固定，确定性）。
- 网点：两套 `radial-gradient` 点阵（6 px 与 13 px），`overlay` 叠加，透明度 0.09–0.11。
- 暗角：椭圆径向渐变 + 上下渐变，中心留出 26–34% 通透区。
- 遮幅：上下各 82 px 近黑边（有效画幅约 2.23:1），带 3 px 柔和投影。
- 月光：月亮本体径向渐变 + 大范围 screen 光晕 + 细描边环。

## 运动语言

- 硬切为主，不用淡入淡出转场（除白闪与黑场）。
- 镜头：缓慢匀速推近（1.05–1.07）+ 单次 `power4.out` 硬 snap，制造"心跳"。
- 主体：从画外进入（位移 + 轻微缩放），进入后保持 1–2° 的呼吸式摆动。
- 强调：文字用缩放 + 字距变化；线条用 `scaleX` 从 0 到 1；光线用 clip-path 横扫。
- 节奏：每镜至少两个状态变化；总长 20 s，切点落在 144 / 306 / 432 帧。

## 连续性规则

- 月亮与金环保持成对出现（shot-001 建立 → shot-003 复用同一金环质感）。
- 绯红只做强调色，不铺满画面（shot-004 例外，用于落版反转）。
- 每镜都以遮幅 + 颗粒 + 暗角收口，保证混剪时质感统一。
- 文字永不出现 ShotBrief 标题、镜头序号或完整字幕。
